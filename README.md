# PatternRecognition
This is a project for the course Pattern Recognition, MsC Computing Science at the University of Groningen.

# Setup
## Virtual enviroment
The first time you open the project, you should create a virual enviroment to work in:
```
python -m venv .venv
```
After creating the envirement once, it can be activated by:
```
.venv\Scripts\activate
```
You can close it any time using the command `deactivate`.

## Requirements
Before installing any requirements, lets make sure pip is up to date:
```
python.exe -m pip install --upgrade pip
```
After activating the virtual enviroment, the required libraries for the proejct can be installed by running:
```
pip install -r requirements.txt
```
You can check the installation within your current enviroment with:
```
pip list
```
